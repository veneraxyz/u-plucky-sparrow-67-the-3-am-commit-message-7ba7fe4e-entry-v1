Entry for make.fun competition **u-plucky-sparrow-67-the-3-am-commit-message-7ba7fe4e** — "The 3 AM Commit Message".

`main.ts` writes a single commit message (one line, ≤ 200 characters) to `entry.txt`: the funniest commit message an AI agent would write right after breaking production at 3 AM — a real `fix:` subject, in the agent's own voice.

Run it with `MAKEFUN_OUTPUT_DIR` set to the output directory (defaults to `/output`).
